Impresora

helpConectar la impresora

  1. Enciende la impresora y carga papel de 58 mm.
  2. Teléfono o tableta: toca «Abrir Bluetooth del teléfono» y vincúlala (PIN 0000 o 1234).
  3. Regresa a la app, toca «Buscar vinculadas» y selecciónala.
  4. Toca «Probar conexión»: debe decir «Impresora conectada».
  5. Computadora con USB: instala el controlador y usa «Impresora del sistema» o «USB / Bluetooth directo».
  6. Toca «Imprimir prueba»: deben salir acentos y ñ correctamente.

Si no conecta: apaga y enciende la impresora, revisa que no esté conectada a otro teléfono o computadora (solo acepta uno a la vez) y acércala. Si sigue igual, en el Bluetooth del teléfono elige «Olvidar» y vuelve a vincularla.

chatAPI de WhatsApp (Meta Cloud API)

Conecta el número del negocio para enviar confirmaciones de citas, tickets y las respuestas del bot.

helpCómo conectarla

  1. Entra a developers.facebook.com, crea una app de tipo «Empresa» y agrega el producto WhatsApp.
  2. En WhatsApp → Configuración de la API copia el «Identificador de número de teléfono» (no el número).
  3. Crea un usuario del sistema en el Business Manager y genera un token permanente con los permisos whatsapp_business_messaging y whatsapp_business_management.
  4. Pega los datos aquí, guarda y toca «Probar conexión»: debe aparecer el número del negocio.
  5. Para avisar citas a clientes que no te han escrito en 24 h, crea una plantilla aprobada con 6 variables: {{1}} cliente, {{2}} fecha, {{3}} hora, {{4}} servicio, {{5}} duración, {{6}} barbero.

Sin configurar, el sistema abre WhatsApp con el mensaje ya escrito para enviarlo a mano.

Datos para el webhook de Meta

Meta solo puede avisar a una dirección https de internet. Se guarda en este equipo solo para armar la URL de abajo.

helpCómo activar el bot

  1. Conecta primero la API (arriba) y comprueba la conexión.
  2. El servidor necesita una dirección https pública. Lo más sencillo es un túnel gratuito: instala «cloudflared», ejecuta el comando de abajo y pega aquí la dirección que te da.cloudflared tunnel --url http://localhost:3000
  3. En developers.facebook.com → tu app → WhatsApp → Configuración → Webhook, pega la «URL de devolución de llamada» y el «Token de verificación» y toca «Verificar y guardar».
  4. En «Campos del webhook» suscríbete al campo «messages».
  5. Enciende «Responder automáticamente» y escribe al número desde otro WhatsApp.

La computadora del servidor y el túnel deben estar encendidos para que el bot conteste.
